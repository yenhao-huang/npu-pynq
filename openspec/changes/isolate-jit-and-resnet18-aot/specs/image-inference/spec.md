## ADDED Requirements

### Requirement: Optional interpreter boundary
Active export, runtime, ISA, hardware tests, public examples and CD SHALL execute
with the entire `src/jit` directory absent. JIT SHALL import no active packages.

#### Scenario: Delete optional JIT
- WHEN the optional directory is temporarily moved out of the source tree
- THEN the active host suites and compiled image example continue to function.

### Requirement: Compiled image inference
The public ResNet18 notebook SHALL use a package generated by `src/export` and
loaded through `src/runtime`, preserving connect, program/load, image selection,
preprocessing/preview, inference, and prediction blocks. It SHALL accept uploads
and bundled images, report ImageNet top-5 labels, and record every block's wall
time and the sum excluding user wait time.

#### Scenario: Real PYNQ picture
- GIVEN compiled ARM code and a matching ISA overlay on PYNQ-Z1
- WHEN a user selects the pinned demo photograph
- THEN inference executes positive physical NPU jobs and predicts Samoyed
- AND records board identity, package identity, counters and block durations.
