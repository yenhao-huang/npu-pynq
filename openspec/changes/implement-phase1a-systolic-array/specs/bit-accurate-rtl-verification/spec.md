## Purpose

Defines reproducible evidence that PE and systolic-array RTL agree with the
Phase 0 golden model across arithmetic, control, and randomized matrix cases.

## ADDED Requirements

### Requirement: Self-checking deterministic simulations
Verification SHALL include self-checking PE and array simulations that return
nonzero or emit a repository-detectable failure marker on mismatch. Tests SHALL
cover signed endpoints, positive and negative saturation, reset, clear,
independent valid bits, mid-job stall, skew scheduling, non-square physical
arrays, and logical shapes smaller than the array.

#### Scenario: RTL mismatch
- **WHEN** any observed value or control state differs from its expected value
- **THEN** the simulation reports the exact case and fails the repository simulation gate

### Requirement: Seeded differential vectors
A tracked deterministic vector generator SHALL use the Phase 0
`matmul_int8` golden model to create signed matrix inputs and expected INT32
outputs. Randomized verification SHALL use an explicit seed, include at least
100 cases, include signed endpoint values, and be exactly reproducible.

#### Scenario: Repeat vector generation
- **WHEN** vector generation is run twice with the same seed and case count
- **THEN** both generated byte streams and expected results are identical

#### Scenario: Random differential pass
- **WHEN** RTL executes every generated matrix case with optional deterministic stalls
- **THEN** every active accumulator equals the corresponding golden INT32 output and unused accumulators remain zero

### Requirement: Validation evidence boundaries
Phase 1A completion SHALL require focused Python vector tests, SystemVerilog
compilation, PE simulation, array simulation, strict OpenSpec validation, and
repository lint/simulation gates when their tools are available. Missing Make,
Verilator, Vivado, or board tools SHALL be reported as blockers and SHALL not
be represented as passed by a narrower simulation.

#### Scenario: Icarus-only host
- **WHEN** direct Icarus compilation and simulation pass but GNU Make or Verilator is unavailable
- **THEN** Icarus evidence is recorded as passed and the unavailable repository or lint gates remain explicitly blocked
