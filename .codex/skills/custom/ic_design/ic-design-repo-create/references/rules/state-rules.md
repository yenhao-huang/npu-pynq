# State Rules

Use `STATE.md` to record creation or maintenance of this skill. Reset it from
`references/template/STATE.template.md` for a new maintenance run.

Allowed statuses are `pending`, `in_progress`, `completed`, `blocked`, and
`skipped`. Mark a step completed only with concrete file or command evidence.
Record the commit or path of every file moved during a restructure so the change
is reversible. Never record credentials or runner registration tokens.
