# Official AMD installer

Use AMD's 2026.1 development-tools download page:

- https://www.amd.com/en/support/downloads/adaptive-socs-and-fpgas/development-tools/2026-1.html

For Windows, choose **AMD Unified Installer for FPGAs & Adaptive SoCs 2026.1: Windows Self Extracting Web Installer**. The file published on the page is:

```text
FPGAs_AdaptiveSoCs_Unified_SDI_2026.1_0616_1700_Win64.exe
```

It is a web installer: the initial executable is not the complete Vivado installation and will download the selected tools and device files afterward. AMD account sign-in may be required before the executable download begins.

Source: AMD, [Adaptive SoCs & FPGA Design Tools Downloads – 2026.1](https://www.amd.com/en/support/downloads/adaptive-socs-and-fpgas/development-tools/2026-1.html).
