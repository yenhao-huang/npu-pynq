## Roadmap progress reached

| Roadmap phase | Proposed state | Evidence |
| --- | --- | --- |
| Phase 2A — ResNet enablement | Complete, already released in v0.1.4 | Issues #33–#36; PRs #37, #38, #40–#42 |
| Phase 2B — ResNet-18 acceptance | Complete, extended with a real-image demo | Issues #7, #47, #49; PRs #46, #48, #69 |
| Phase 2C — Production hardening | Not included | Issue #8 closed without a merged implementation PR |

New in this upload: the 8 x 8 systolic target replaces 2 x 2 as the ResNet
demo default, and the notebook classifies a real photograph instead of only the
synthetic validation tensor.

The physical PYNQ-Z1 run recorded in `examples/resnet18/resnet18.ipynb`
completed 135,290 physical jobs and 1,814,073,344 MACs in 66.8 minutes, and
predicted `zebra` at 79.43% against an expected class of `zebra`. The same
picture scores 79.4% through the host INT8 path.

That run is a demonstration, not strict release acceptance. The notebook no
longer performs a per-capture digest comparison and writes no evidence file;
deterministic digest-checked acceptance remains in `run_on_board.py` on the
synthetic tensor. It is also a single labelled photograph, so it is not an
ImageNet accuracy result.
