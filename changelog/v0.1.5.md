synthetic validation tensor.

predicted `zebra` at 79.43% against an expected class of `zebra`. The same
picture scores 79.4% through the host INT8 path.

That run is a demonstration, not strict release acceptance. The notebook no
longer performs a per-capture digest comparison and writes no evidence file;
deterministic digest-checked acceptance remains in `run_on_board.py` on the
synthetic tensor. It is also a single labelled photograph, so it is not an
ImageNet accuracy result.

## Release package

This version is published by continuous deployment: a push to `main` declaring
`changelog/v0.1.5.md` runs host checks, the Vivado build, package assembly, and
physical PYNQ-Z1 acceptance, and only a passing run creates the `v0.1.5` tag
and this Release. Nothing here was published before the board accepted it.

| Asset | What it is |
| --- | --- |
| `npu-resnet18-v0.1.5.zip` | Standalone ResNet-18 board package: notebook, runtime, quantized model, ImageNet labels, demo photographs, verified overlay, Vivado build reports |
| `npu-matrix-v0.1.5.tar.gz` | Standalone Phase 1C matrix example |
| `npu_matrix.bit`, `npu_matrix.hwh`, `npu_matrix.manifest.json` | Deterministic 8 x 8 overlay artifacts and their provenance |
| `build_evidence.txt` | Vivado version, part, worst negative slack, failing setup paths, DRC errors |
| `board-evidence.json`, `resnet18-board-evidence.json` | Physical acceptance-corpus evidence |
| `resnet18-image-acceptance.json` | Physical real-image inference: input image and provenance, top-5 prediction, verdict |
| `SHA256SUMS` | Digests covering every package and artifact above |

### Quick start

1. Download `npu-resnet18-v0.1.5.zip` and copy it to the board's Jupyter
   directory.
2. Extract it on the board: `unzip npu-resnet18-v0.1.5.zip -d npu-resnet18`.
3. Open `resnet18.ipynb` and run the cells in order; the last cell prints the
   top-5 ImageNet labels with their scores and a CORRECT or INCORRECT verdict.

Prerequisites: a PYNQ-Z1 running the PYNQ image with Jupyter reachable, and
about 1.5 hours. No Vivado, no PyTorch, and no internet access on the board.

### Known limitations

- One forward pass is 1,814,073,344 MACs and takes roughly an hour on the 8 x 8
  overlay.
- The bundled photographs are Creative Commons images, not ImageNet dataset
  images, so a correct prediction is a demonstration, not an accuracy result.
- The package requires the 8 x 8 overlay with `MAX_K=256`.
- The pinned TorchVision checkpoint is not redistributed; the exported INT8
  model is.
