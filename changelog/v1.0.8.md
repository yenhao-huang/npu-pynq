New in this upload: models are compiled ahead of time into a
`pynqo-package/2` package: `model.so` per CPU, `weights.bin`, and NPU ISA
programs that the runtime dispatches through `__delegate__`. The runtime is
split into a shared loader and per-task engines (`llm`, `classifier`) behind
one entry point, `python -m src.runtime.cli`. The just-in-time stack moved to
`src/deprecate/jit/`. The overlay gains an ISA front end, so the v1.0.7
BIT/HWH pair cannot run v1.0.8 packages; this release ships its own rebuilt
overlay.

The release workflow is rebuilt around the example guides (#145): each model
is exported, packaged with `src/deploy/deploy.sh` and run on the board with
the guide's own command, and must match the host simulator. The Release
carries `pynqo-resnet18-v1.0.8.tar.gz`, `pynqo-smollm-v1.0.8.tar.gz`, their
board results, the bitstream and one `SHA256SUMS`; the matrix example is no
longer a release asset.

Before this release run, SmolLM2-135M-Instruct ran on the PYNQ-Z1 with output
matching the host simulator (2026-11-01, prefill about 37-48 s, decode about
0.5 tokens/s). ResNet-18 classified the demo picture as Samoyed at 90.20% on
the host simulator through the new package (21 delegates, 35,174 jobs). The
release run for `release/v1.0.8` is the hardware evidence for this release; its
results are recorded here once it passes.
