## Roadmap progress reached

| Roadmap phase | Proposed state | Evidence |
| --- | --- | --- |
| Hardware optimization for larger configurations | Banked operands, packed 64-bit input, pipelined jobs with A/B ping-pong buffering, and a 16 x 16 default overlay | Issues #59, #64, #93, #108; PRs #60, #94, #97, #111 |
| Controller structure and verification | Modular accelerator RTL and documented packed-stream cycle evidence | Issues #62, #93; PRs #103, #102 |
| Phase 2C — Production hardening | Not included | — |

New in this upload: the operand input stream carries eight INT8 values per
64-bit beat (AXI DMA MM2S at 64 bits), fed through a row aligner into the
per-row and per-column operand banks. In RTL simulation a stall-free 8 x 8
job with K = 256 drops from 4,433 cycles (v1.0.6 controller) to 596. This
8 x 8 result is simulation evidence; the release overlay defaults to 16 x 16.

The input stream interface changed, so the v1.0.6 overlay is not compatible
with this release's verifier; this release ships its own rebuilt overlay.
The newly modularized accelerator also changes the Vivado instance name to
`npu_accelerator_0`, so the older BIT/HWH pair cannot be reused. The A/B
ping-pong buffer overlaps adjacent jobs. A 16-job, 8 x 8 x 64 RTL sweep fell
from 3,456 serialized cycles to 2,390 pipelined cycles; this is simulation
evidence, not a physical-board result. CD run
[37253561425](https://github.com/yenhao-huang/npu-pynq/actions/runs/37253561425)
built the 16 x 16 overlay at 100 MHz with routed WNS +0.067 ns and WHS
+0.041 ns. Its physical PYNQ-Z1 image acceptance passed on ResNet-18:
Samoyed was the correct top-1 class at 90.4% in 35,174 physical jobs and
1,896.1 seconds. Routed utilization was 32,804 LUTs, 21,569 FFs, 192 DSPs,
and 26.5 BRAM tiles.
